# Basic HTML Labs

This folder contains **basic HTML practice projects** from FreeCodeCamp's Responsive Web Design curriculum.  

The exercises focus on:

- Writing clean and semantic HTML  
- Understanding content structure and hierarchy  
- Practicing HTML tags like headings, paragraphs, lists, links, images, and multimedia  

### Projects Included

- `html-css-js-introduction.html` – Basic page structure introducing HTML, CSS, and JavaScript  
- `pet-adoption.html` – Simple pet adoption page with images and links  
- `cat-photo-app.html` – Cat photo gallery with headings, paragraphs, lists, and figures  
- `chocolate-chip-cookies.html` – Recipe page with lists and images  
- `xyz-bookstore.html` – Bookstore layout with headings, paragraphs, and buttons  
- `travel-agency-page.html` – Travel agency page with packages, images, and figures  
- `html-video-element.html` – Demonstrates embedding a video with multiple sources
- `html-audio-video-player.html` – Demonstrates `<audio>` and `<video>` elements  
- `svg-heart-icon.html` – Inline SVG example rendering a heart icon  
- `iframe-video-embed.html` – Embeds a YouTube video using `<iframe>`  
- `video-compilation-page.html` – Showcases multiple favorite videos in sections
