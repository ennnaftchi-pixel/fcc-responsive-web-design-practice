# Forms & Tables

This folder contains HTML labs focused on building accessible forms and well-structured data tables using semantic markup.

These exercises emphasize:

- Proper form structure and labeling
- Input validation attributes
- Fieldsets and legends
- Accessible controls
- Semantic table elements
- Table captions and grouped sections

---

## Projects

### Hotel Feedback Form
- Multi-section feedback form  
- Uses fieldsets, legends, labels, and validation attributes  
- Includes radio buttons, checkboxes, dropdowns, and textarea  

### Calculus Final Exams Table
- Grade table using semantic table structure  
- Demonstrates `<caption>`, `<thead>`, `<tbody>`, and `<tfoot>`  

### Book Catalog Table
- Structured catalog of books  
- Uses grouped table sections and column headers  
- Focuses on readability and accessibility
