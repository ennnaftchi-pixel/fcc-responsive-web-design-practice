# Semantic HTML Labs

This folder contains **semantic HTML practice projects** from FreeCodeCamp's Responsive Web Design curriculum.  

The exercises focus on:

- Using semantic HTML elements like `<header>`, `<footer>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<blockquote>`, `<q>`, `<cite>`, and `<address>`  
- Structuring content for clarity, accessibility, and readability  
- Practicing proper markup hierarchy and meaningful content separation  

### Projects Included

- `web-browsers-list.html` – Uses `<dl>` to list major web browsers and descriptions  
- `quincy-dev-job-tips.html` – Organizes tips for developers using `<section>` and `<blockquote>`  
- `mr-whiskers-blog.html` – Blog page with `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<figure>`, and `<address>`
