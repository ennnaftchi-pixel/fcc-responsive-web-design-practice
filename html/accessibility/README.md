# Accessibility Projects

This folder contains **HTML projects focused on web accessibility**.  
These exercises were completed as part of **FreeCodeCamp’s Responsive Web Design curriculum**, emphasizing accessible and inclusive web design.

---

## About This Folder

Accessibility is a key aspect of web development, ensuring that all users, including those with disabilities, can access and interact with content.  

These projects demonstrate:
- Proper use of semantic HTML  
- Accessibility attributes like `aria-label`, `aria-labelledby`, and descriptive `alt` text  
- Structuring content for screen readers and keyboard navigation  

---

## Projects

### Camperbot's Blog (`camperbot-blog.html`)
- A simple blog page with **semantic structure**, including `<main>`, `<nav>`, `<article>`, and `<footer>`  
- Focuses on accessible navigation for screen readers  

### Tech Conference 2025 Schedule (`tech-conference-schedule.html`)
- Conference schedule presented in a table  
- Uses `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, and proper `<th scope>` attributes  
- Emphasizes **accessible tabular data**

### Donation Form (`donation-form.html`)
- Accessible form with proper `<label>` associations and input types  
- Checkbox for newsletter subscription demonstrates accessible form controls  

### Accessible Controls (`accessible-controls.html`)
- Example of using `<button>` and `<input type="range">` with `aria-labelledby`  
- Demonstrates **labeling controls for assistive technologies**  

### Checkout Page (`checkout-page.html`)
- Form with credit card inputs and ARIA descriptions  
- Uses `<span aria-hidden="true">` and `aria-describedby` for accessibility  

### Movie Review (`movie-review.html`)
- Example of multimedia content with accessible text, images, and ratings  
- Emphasizes **accessible media presentation**

### Multimedia Player (`multimedia-player.html`)
- Combines `<audio>` and `<video>` elements with captions and labels  
- Demonstrates **accessible multimedia experiences**
