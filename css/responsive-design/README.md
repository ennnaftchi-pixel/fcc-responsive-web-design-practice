# Piano — Responsive Design Project

A responsive CSS layout project that builds a piano keyboard using floats, pseudo-elements, and media queries.

---

## Concepts Practiced

- Responsive design with media queries
- Layout scaling for different screen sizes
- Pseudo-elements (`::after`)
- Float-based layout
- Absolute positioning
- Component styling and layering

---

## Features

- Piano keyboard built entirely with CSS
- Black keys created with pseudo-elements
- Responsive resizing for small and medium screens
- Centered layout with adaptive widths
- Decorative branding logo positioning

---

## Files

- `index.html` — Piano structure and key layout
- `styles.css` — Responsive styling and media queries
