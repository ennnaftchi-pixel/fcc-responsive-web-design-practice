# CSS Variables Module

This folder contains **projects and exercises focused on CSS variables** (custom properties) as part of FreeCodeCamp’s **Responsive Web Design curriculum**.

---

## Concepts Covered

- Using `:root` to define CSS variables
- Assigning variables to colors, sizes, and other properties
- Changing variables dynamically via media queries
- Using variables to maintain consistent design across multiple elements
- Practicing layering, gradients, and Flexbox layouts

---

## Projects

### City Skyline
**Folder:** `variables/city-skyline/`

- Demonstrates CSS variables with foreground and background building layers
- Uses Flexbox to align and distribute buildings
- Windows and building colors controlled with variables
- Responsive night mode using variable overrides
