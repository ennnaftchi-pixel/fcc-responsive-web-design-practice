# Book Inventory

A CSS attribute selectors project that styles a book inventory table using precise selector targeting.

---

## Concepts Practiced

- CSS attribute selectors (`[class=""]`, `[class^=""]`, `[class~=""]`)
- Table styling and layout
- Conditional row styling based on status
- Nested selector targeting
- Visual rating indicators using spans
- Gradient backgrounds and borders

---

## Features

- Status-based row coloring
- Attribute-driven styling rules
- Visual rating dots filled based on class values
- Structured and readable table layout
- Selector precision without extra classes or IDs

---

## Files

- `index.html` — Book inventory table structure
- `styles.css` — Attribute selector styling rules
