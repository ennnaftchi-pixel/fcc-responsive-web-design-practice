# CSS Colors

This folder contains projects focused on learning and practicing **CSS color systems and color-related styling** from the FreeCodeCamp Responsive Web Design curriculum.

These exercises explore how colors work in CSS using multiple formats and how they affect visual design and readability.

---

## Topics Covered

- Named colors
- Hex color values
- RGB and RGBA colors
- HSL and HSLA colors
- Gradients
- Opacity and alpha channels
- Background colors and color contrast

---

## Projects

### Colored Boxes
**Folder:** `colored-boxes/`

- Displays a grid of colored boxes
- Demonstrates multiple CSS color formats:
  - Hex
  - RGB
  - Named colors
  - HSL
- Uses flex layout for alignment
- Focuses on comparing color systems visually

---

## Purpose

These projects build a strong foundation in how CSS handles color and how different color formats can be used depending on context and design needs.
