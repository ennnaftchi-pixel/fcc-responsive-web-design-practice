# Basic CSS Projects

This folder contains small projects and components built while learning the **CSS fundamentals** section of the FreeCodeCamp Responsive Web Design curriculum.

The focus here is on understanding how CSS controls layout, typography, colors, spacing, and interactive states.

Each project is intentionally small and focused on one or two core styling concepts.

---

## Skills Practiced

- CSS selectors and class targeting  
- Typography and font styling  
- Colors and backgrounds  
- Spacing (margin & padding)  
- Borders and border-radius  
- Shadows and visual depth  
- Link and button states (`:hover`, `:active`, `:visited`, `:focus`)  
- Component-style layout patterns
