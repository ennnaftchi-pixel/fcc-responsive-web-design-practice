# CSS — Attribute Selectors

This module focuses on using **CSS attribute selectors** to target elements based on attributes and attribute values instead of only classes and IDs.

It demonstrates accessibility helpers, semantic markup, and precise selector targeting.

---

## Balance Sheet Project
**Folder:** `CSS/attribute-selectors/balance-sheet-project/`

- Financial balance sheet layout using semantic HTML tables
- Uses CSS attribute selectors like `[class~="sr-only"]` and `[class]`
- Demonstrates visually-hidden accessibility patterns
- Includes sticky headers and structured table styling
- Focuses on accessibility + selector precision
