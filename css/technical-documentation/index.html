Introduction

JavaScript is a versatile programming language primarily used for web development.

It allows developers to create dynamic and interactive web pages.

console.log('Hello, world!');

It is executed in the browser and can also run on the server via Node.js.

  • Dynamic typing
  • Event-driven programming
Variables and Constants

Variables can be declared using var, let, or const.

Constants declared with const cannot be reassigned.

let x = 10; const y = 5;
  • Scope matters: block vs function
  • Hoisting affects var
Functions

Functions allow code reuse and modularity.

They can be declared in multiple ways.

function greet(name) { return 'Hello ' + name; } const greet = (name) => `Hello ${name}`;
  • Function declarations
  • Function expressions
Loops

Loops allow repeated execution of code blocks.

JavaScript supports for, while, and do...while loops.

for (let i=0; i<5; i++) { console.log(i); } while(condition) { /* code */ }
  • Control flow with break and continue
Events

Events are actions that occur in the browser.

JavaScript can respond to these events using event listeners.

element.addEventListener('click', handleClick); function handleClick() { alert('Clicked!'); }
  • Click events
  • Keyboard events
