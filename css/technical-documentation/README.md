# Technical Documentation Page — Responsive CSS Project

A certification project that demonstrates a fixed navigation sidebar with scrollable main content for documentation pages.

---

## Concepts Practiced

- Fixed sidebar navigation
- Scrollable main content
- Responsive design for small screens
- Section highlighting and anchor links
- CSS typography and spacing

---

## Features

- Fully scrollable documentation layout
- Fixed navigation with anchor links
- Section styling with headers, code blocks, and lists
- Responsive adjustments using media queries
- Lightweight and semantic HTML

---

## Files

- `index.html` — Structure of the documentation page
- `styles.css` — Layout, navigation, and responsive styles
