# Typography — CSS Projects

This folder contains projects focused on **typography, font styling, and text layout** in CSS.

Topics practiced:

- Using web fonts (Google Fonts)
- Font weights, sizes, and styles
- Text alignment, spacing, and indentation
- First-letter styling and emphasis
- Multi-line text formatting and hierarchy

---

## Projects

### Nutrition Label
**Folder:** `css/typography/nutrition-label/`

- Builds a nutrition facts label using CSS typography and layout
- Demonstrates font sizing, font weight, text alignment, and spacing
- Uses divs, spans, and classes for structured textual hierarchy

### Newspaper Article
**Folder:** `css/typography/newspaper-article/`

- Creates a newspaper-style article layout
- Uses headings, sub-headings, and paragraphs with proper font weights and sizes
- Demonstrates text indentation, line height, and first-letter emphasis
- Focuses on readable, print-style typography in a web page
