# Absolute and Relative Units

This folder contains CSS projects that demonstrate the use of **absolute and relative units** in styling web pages.

## Projects

### Event Flyer
**Files:** `event-flyer/index.html` & `event-flyer/styles.css`

- A styled event flyer page with header image and content sections  
- Demonstrates layout using percentages, `vw`, `vh`, and other relative/absolute units  
- Focuses on spacing, typography, and responsive layout basics
