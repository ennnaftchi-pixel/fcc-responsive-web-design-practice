# Pseudo-Classes and Pseudo-Elements

This folder contains CSS projects that focus on **pseudo-classes and pseudo-elements** for styling.

## Projects

### Greeting Card
**Files:** `greeting-card/index.html` & `greeting-card/styles.css`

- Interactive birthday greeting card  
- Demonstrates `:hover`, `:focus`, `:active`, and `::before`/`::after` pseudo-elements

### Parent Teacher Conference Form
**Files:** `parent-teacher-conference-form/index.html` & `parent-teacher-conference-form/styles.css`

- Form layout for scheduling parent-teacher conferences  
- Uses pseudo-classes for input focus, checked states, and validation feedback

### Job Application Form
**Files:** `job-application-form/index.html` & `job-application-form/styles.css`

- Job application form with radio buttons, text inputs, select, and textarea  
- Demonstrates pseudo-classes for focus, valid/invalid states, hover effects, and custom radio styling
