# CSS Grid Module

This folder contains projects built while learning **CSS Grid Layout** in the FreeCodeCamp Responsive Web Design curriculum.

The focus of this module is:

- Two-dimensional layouts with rows and columns
- Grid template areas
- Grid alignment and spacing
- Combining Grid with responsive design techniques

CSS Grid is especially useful for page-level layouts and complex structured designs.

---

## Projects

### Magazine Layout
**Folder:** `magazine-project/`

- Magazine-style responsive layout
- Uses grid columns and content sections
- Combines typography, images, and structured content
- Demonstrates multi-section grid composition

---

### Newspaper Layout
**Folder:** `newspaper-layout/`

- Newspaper-style grid layout
- Uses `grid-template-areas`
- Demonstrates multi-row content structure
- Combines feature article, image block, and small article grid
